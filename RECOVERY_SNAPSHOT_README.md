# Modular LumenForge recovery snapshot

This repository is an independent archival snapshot of the recovered modular source, not a continuation of or integration into the existing LumenForge Git history.

The 55 files listed in provenance/SOURCE_SHA256_MANIFEST.json were copied from the recovered source and hash-verified before staging and again after copying. The original recovery ZIP and recovered directory are kept outside this repository and must remain unchanged.

Reports in provenance/ are historical audit artifacts. Any historical/unverified build or performance statements remain unverified unless the report explicitly provides reproducible evidence. This commit does not implement changes, optimize export, establish performance root cause, merge histories, or change CUDA work.

Excluded by design: executables/binaries, ZIP archives, caches, virtual environments, temporary build outputs, and secrets. Runtime candidates remain on the original machine.
