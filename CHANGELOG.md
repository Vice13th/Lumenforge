# Changelog

## v12.0 — Public distribution baseline

- Premium dark 3-column desktop UI.
- Preset search and favorites.
- `Phones` category combines iPhone and Samsung presets.
- `Cinematic Cameras` category groups ARRI Alexa, RED Digital Cinema, Sony Venice, Blackmagic Design, Canon Cinema EOS, and Panavision/Light Iron presets.
- Command Palette remains available through `Ctrl+K`; its toolbar icon is intentionally hidden.
- Integrated LumenForge brand mark and application icon.
- Public distribution is free-to-use while proprietary source remains closed.


## 2026-09-12 — Windows Release

- Added the ready-to-run Windows executable at `dist/LumenForge.exe`.
- Refreshed public branding assets.
- Kept proprietary Python source out of the public repository.
