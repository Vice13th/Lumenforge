The philosophy

Lumen Forge treats colour as a first-class processing problem: source → camera interpretation → scene preparation → tone → colour → local adjustments → optical/film effects → output.

Built for control

RAW-aware loading, Camera DNA approximation, 3D LUTs, masks, HSL, film curves, halation, bloom, grain, non-destructive state, command palette and cached interactive preview.

Honest by design

Camera DNA is documented as approximation where proprietary manufacturer colour science is unavailable. Source inventory counts are not presented as performance benchmarks.

Built as a project landing page from the repository's documented architecture and evidence boundaries. No benchmark, scientific validation, or hardware receipt is implied beyond what the repository records.
